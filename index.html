Aligning Machine Learning Explanations with User Knowledge via PDP-Guided Data Augmentation

A No-Code System for Incorporating Domain Knowledge into ML Models

PDGA enables users to intuitively edit Partial Dependence Plots (PDPs) to incorporate their domain knowledge into machine learning models. By directly editing PDP curves through a graphical interface, users can align model explanations with their expertise—without requiring any ML knowledge.

System Demonstration

Abstract

We introduce PDP-Guided Data Augmentation (PDGA), a model-agnostic system that synthesizes training data to build machine learning (ML) models whose explanations align with user knowledge. PDGA focuses on Partial Dependence Plot (PDP), a commonly used explainable AI method that visualizes the effect of features by plotting predictions across varying feature values. PDGA enables intuitive PDP editing, allowing users to incorporate their knowledge into a model without requiring ML expertise. Users can directly edit PDP curves on the screen so that the modified curves reflect their knowledge. The system then synthesizes training data and retrains the model using it so that its PDP aligns with the user-specified curve. We demonstrate its effectiveness using real-world datasets, showing that the discrepancy between the model's PDP and the user-specified PDP is reduced by over 90% while largely maintaining or improving predictive performance.
